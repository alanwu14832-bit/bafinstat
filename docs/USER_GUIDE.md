# NTU BaFiN 數據平台 使用手冊

整個流程只需要一份 Excel 總表（`data/BAFIN_棒球數據總表.xlsx`）和網站。網站上的「使用指南」頁有同樣內容。

## 一、角色分工
| 角色 | 做什麼 | 需要登入？ |
|---|---|---|
| 紀錄員 | 比賽當天記錄、賽後貼回總表、上傳網站 | 是（Supabase 帳號） |
| 隊員／教練 | 開網站看數據 | 否 |

## 二、比賽前（5 分鐘）
1. 打開總表（建議放在共用雲端硬碟，整隊只維護這一個檔案）。
2. `比賽清單` 新增一列：比賽ID `G+日期+場次`（例 `G20251010-01`）、日期、杯賽、對手、主客、場地。杯賽與對手名稱先在 `設定` 的清單裡加好，之後下拉選單才有。
3. 複製三張模板：右鍵工作表 → 移動或複製 → 建立副本：`單場-摘要`、`單場-打擊`、`單場-投球`。在 `單場-摘要!C2` 填同一個比賽ID，填先發打序與守位；賽後在同一區塊填勝投／敗投／救援（網站的 W／L／SV 由這裡來）。

## 三、比賽中：用哪一張表

> **不想用 Excel？** 紀錄員登入後到網站「紀錄比賽」頁：填比賽資訊與先發（會帶入「先發陣容」頁排好的陣容，否則帶上一場打序；球員一律下拉選）→ 每球點 B／CS／SS／F／IP → 點結果 → 選落點和軌跡（打進場內的球兩個都必填，沒選「送出」按不下去；強度一開始就是「中」，要改再點強或弱）→ 確認跑者去向 → 送出。局數、出局、壘上、得分、殘壘、結果代碼全部自動；每球送出後自動存到雲端、全隊即時看得到進度（自動儲存失敗時會出現「重試儲存」），賽後「結束比賽」填勝敗投（中繼可以複選）即完成。從賽程與「先發陣容」帶入的比賽資訊和打序會先收成摘要，要改再按「修改」；滾地、飛球類結果會自動帶入軌跡。
>
> 打席區上方的狀態列告訴你現在在記「打擊」（我隊進攻）還是「投球」（對方進攻，預設只記第幾棒；想記姓名見下方「對方打者」說明）。壘上跑者點一下可記盜壘、牽制（安全或出局）、進壘；「全螢幕」讓紀錄頁佔滿整個畫面；「大字」把按鈕和字放大一級（大太陽下比較好看，這台裝置會記住）。按鈕下方的狀態列會說最新一球是否已同步到雲端（綠點已同步、黃點尚未同步、紅字同步失敗＋「重試儲存」）。
>
> **相簿**：照片放在攝影師自己的 Google Drive（資料夾設「知道連結的人可檢視」），紀錄員到「相簿」頁把連結貼在對應的比賽；隊員不用登入，點「開啟相簿」就能看和下載原檔。
>
> **比賽時間、對方投手、對方打者**：第一球和最後一個打席的時間會自動記下（紀錄畫面下方出現「13:07 開賽」），「結束比賽」時帶出開賽、結束時間和比賽時間，可以修改（看影片補記請改成實際時間）。我隊第一次打擊前畫面上方會問「對方投手是？」，**一定要選**：點「左投」或「右投」（看不出來就按「不知道」，也可以「填姓名」），選好之前投球按鈕和打擊結果按不下去；對方換投時也一樣要選左投／右投／不知道才能按「換投」（以前的「不記」拿掉了，舊進度按過不記的會再問一次）；之後點「代打」旁的「對方 右投」：**記錯了**（同一位投手，左右投或姓名填錯）選「更正這位投手」，他今天投過的打席一起改、「對方投手 N 球」照算；**對方換投**選「對方換投」，從下一個打席起記新投手、球數從 0 算。之後每個打席自動記上，用來看對左投／對右投的成績。賽後在「修改資料」打開我隊的打席，「對方投手」的「修改」也能改：不是那位投手第一個打席時，可以選「整段都改」或「從這個打席起換投」（雲端要先執行 2026-10-14 的 SQL，見 SUPABASE_SETUP.md）。對方打者姓名預設不記；開始前勾「記對方打者姓名」就能填對方打序，比賽中改名字＝代打。這些姓名和其他資料一樣公開，建議只記背號（例如「12號」）。

> **賽程**：紀錄員在「比賽」頁的「賽程」分頁新增下一場（日期、時間、對手、場地、集合備註），隊員可一鍵加到 Google 日曆；比賽當天在「紀錄比賽」的「從賽程帶入」選這場就開始記，不必重填。
>
> **先發陣容**頁：先選「這份陣容是哪一場」，球場圖上每個守位一個下拉選單、右邊排打序（「依守位填入」一鍵排好、可上下移），再在「板凳（今天有到）」點選到場但沒先發的人，需要時勾「允許被換下的球員再上場」；陣容存在這台裝置，可複製成文字貼群組，或「帶到紀錄比賽」（直接開那一場）。
>
> **逐球跑壘**：投球之間的盜壘、暴投、捕逸、牽制都記在「第幾球之後」：紀錄時點計分條上的壘包打開跑者面板，點跑者、再點發生的事；暴投／捕逸全部進壘直接按投球按鈕下方的「暴投」「捕逸」。賽後「修改資料」點一個打席，在「逐球」區選第幾球後、哪位跑者、發生什麼即可補記，點逐球裡的事件可刪除。安打時多跑的壘：在「跑者去向」把他設到比預設更遠的壘，旁邊出現兩個選項：「趁傳（不算失誤）」＝守備傳別的壘或回傳時多跑，不算誰失誤；「對方失誤進壘」（我隊守備時是「我隊失誤進壘」）＝漏接、暴傳等守備失誤讓他多跑，算一次失誤、那一分不算打點（修改資料也一樣）。Excel 的「跑壘事件」欄是同樣的內容（例如「2 暴投 1-2；3 盜壘 2-3」），可不填。
>
> **失誤（E）怎麼算**：計分板、比賽頁、記分表、分享圖和 Excel 的 E 都用同一個規則，每一次失誤都算：打擊結果「失誤」、捕手妨礙、「失誤進壘」（投球之間或安打時），還有沒讓任何人多跑的失誤。我隊打擊時投球按鈕下方有「對方失誤」：例如對方捕手漏接界外飛球，點「對方失誤」再點 C，看不清楚就點「不知道」；打擊結果是「失誤」那次不用再點。跑者因對方失誤多跑一壘：跑者面板按「失誤進壘」再點是誰（或不知道）。我隊守備時，對方跑者失誤進壘要點我隊誰失誤，那一分算非自責分；修改資料沒點是誰失誤不能儲存。Excel 的打席紀錄最後一個黃色欄是「對方失誤」（填守位，例如 C、SS；不知道填「不明」）。

> **對方打點、對方代打、備註**：對方打擊時送出前可以加減「對方打點」（逐打席投球分頁也能改），對方換人代打按「對方代打」，每個打席送出前都可以填「備註」。我隊打擊時畫面顯示「對方投手 N 球」。Excel 的投球紀錄最後一個黃色欄是「打點」（對方打者的打點）。這些要先在雲端執行 2026-10-15 的 SQL（見 SUPABASE_SETUP.md），沒執行前照常可以記，只是不會存進雲端，存檔時會提醒。

> **對方打者左打／右打**：對方打擊時，「對方第 N 棒」旁邊有「左打｜右打」（沒有「不知道」），**每位打者第一次上場一定要選一個**（選好之前投球按鈕和打擊結果按不下去，畫面寫「先選對方打者左打或右打」）。同一棒這場之後再上來會自動帶入，只要按一次；左右開弓的打者就選他這次站的那邊（下次換邊再點另一個）。對方代打、對方代跑、或在對方打序改了那一棒的名字，會再問一次。記錯按「復原」。即時比分、Box Score、文字轉播會在對方打者旁邊標「左打」／「右打」，對手情蒐也會寫。賽後在「修改資料」打開對方的打席，「對方打者」的「修改」可以選左打／右打／不知道，「整段（同一棒這場）都改」或「只改這個打席」；表格也有「左右打」欄。Excel 的投球紀錄／單場-投球最後一欄是「對方打者左右」（L／R，不知道就空白）。用途：「投球」頁和球員頁的情境拆分多了「對左右打」（我隊投手對左打、對右打的被打擊率、被上壘率、被長打率、被 OPS、K%、BB%）；「打擊」頁的情境拆分多了「左右打」（左打者／右打者合計，以及左打者・對左投、左打者・對右投、右打者・對左投、右打者・對右投），依球員名單的「打擊慣用」，沒填的列成「未填」並寫出是誰，到「球員」頁的球員名單補上。雲端要先執行 2026-10-16 的 SQL（見 SUPABASE_SETUP.md）；沒執行前紀錄畫面不會問對方打者左右打。
> **擊球剖面**：「投球」頁、「打擊」頁的「擊球剖面」分頁，以及球員頁投球區、打擊區的「擊球剖面」表（參考 Baseball Savant 的 Batted Ball Breakdown）。欄位分四組：擊球種類（GB／LD／FB／PU／AIR；PU 是內野飛球，GB＋LD＋FB＋PU＝100%，AIR＝LD＋FB＋PU）、方向（Pull／Center／Oppo：投手用對方打者左右打加落點，打者用球員名單的打擊慣用加落點）、強度（Soft／Med／Hard）、結果（HR/FB 和滾地、平飛、飛球各自的 BABIP）；每個比率旁的小字是 分子/分母，只算有記那一項的擊球；最後一列是全隊，方便對照。FB% 不含內野飛球（以前包含），IFFB%、GB/FB、HR/FB 仍把內野飛球當飛球。Excel 總表的打擊有 GB%／FB%／PU%／AIR%／LD%／Hard%／Pull%／Oppo%，其餘網站專屬。
> **公式不猜資料（資料完整度）**：公式需要的欄位沒填，那個打席（擊球）就不進那一項的分母，不會用猜的補。(1) 打者的 Pull／Center／Oppo 看球員名單的「打擊慣用」：左右開弓的人依那個打席對方投手的左右手（站在相反邊）；沒填慣用的人不算（以前會當右打）。(2) GB%／LD%／FB%／PU% 只算有記軌跡的擊球，不再用結果（內野滾地、外野飛球）推定，因為安打沒辦法推定，推定會讓滾地、飛球比例偏高。(3) 每局用球數 P/IP 只算有記逐球的打席的出局。球員頁按「編輯球員名單」，下方有「資料完整度」表：逐球、軌跡、落點、強度、出局(前)、壘上(前)、棒次、對方左右手各填了幾成、缺了會讓哪些數字的樣本變少（低於 90% 橘色），並列出沒填慣用的打者。Excel 總表同步：沒填慣用手的打者不算拉打／反方向，球員名單的慣用手可填 R／L／S。
> **對左打・對右打／對左投・對右投**：「投球」頁、「打擊」頁各有一張獨立的卡片，每位球員一列，左右兩邊並排（打席數、打擊率、上壘率、OPS、K%，和 左−右 的差）；球員頁的投球區多一張「對左打・對右打」、打擊區多一張「對左投・對右投」。依紀錄比賽時選的對方打者左右打／對方投手左右投，沒記到的打席不算（卡片下方寫有幾個）；打席不到 10 個的數字變淡。
> **半局中途結束的球、換投時的球數**：盜壘失敗或牽制當第三個出局而打席沒打完時，已投的球記成一列「未完成打席」（不算打席）；打席投到一半換投，換下的投手已投的球算他自己（接手那一列的「跑壘事件」欄會有「換投前 林昱丞 3」）。總表的 PC 仍是每位投手那幾列的球數，不分這種拆法。
> **安打後被刺殺**：安打或失誤的打擊球上，打者上壘後被刺殺、跑者多跑被傳殺，都會記一筆（跑者是「被刺殺」，自己的跑壘失誤是「壘死」），並可以選死在哪個壘包；「打擊」頁過程指標有 XBT%、擴張被殺、被刺殺（網站專屬）。

> **對方代跑**：對方打擊時點壘包上的對方跑者，在「壘上跑者」最下面的「代跑：換上…」填代跑的姓名或背號（選填，空著就記成「對方代跑」），按「換上代跑」；記錯按「復原」。他留在原來的壘上、在他上壘的那一列記成代跑，之後的盜壘、牽制、得分照樣點他；**只換名字，我隊投手的失分、自責分不變**。有勾「記對方打者姓名」時，對方打序那一棒也換成他。逐打席、記分表、即時比分都會標「代跑 12號」。賽後在「修改資料」對方那一列的「代跑」欄可以補上或改；Excel 的投球紀錄／單場-投球最後一欄是「代跑」。這些姓名一樣公開，建議只記背號（雲端要先執行 2026-10-15 的 SQL，見 SUPABASE_SETUP.md；沒執行前照常可以記，只是對方代跑不會存進雲端，存檔時會提醒）。

> **延長賽突破僵局**：預設從規定局數的下一局起（系隊第 8 局），每個半局一開始一、二壘有人、無人出局；一壘跑者是這局第一位打者的前一棒，二壘是前兩棒（WBSC 規則）。打到那一局時，紀錄畫面先出現「延長賽突破僵局」卡片，列出誰上哪一壘和接下來的打者，按「放上跑者」就排好（記錯按「復原」）；這局不用按「這局不用」。開賽前可在比賽資訊的「突破僵局」選從第幾局起或「不採用」、「放哪幾壘」選一、二壘／二壘／滿壘（這台裝置會記住）；比賽中在卡片上按「改規則」。卡片出現時投球按鈕會先停用，換投、代打照常可以按；要代跑，放上去後點壘包換人。這些跑者**不算打席、打數**；他跑回來算他自己的得分，打回他的人照算打點；對方的突破僵局跑者回來得分一律是**非自責分**（規則視同失誤上壘，但不算失誤）。賽後在「修改資料」延長局的標題按「＋ 突破僵局跑者」可以補上（網站沒存預定局數，所以按鈕出現在第 5 局之後、平手打進來的局；比賽已經有突破僵局跑者時，從那局起每局都有；後面打席的壘上跑者會跟著更新，得分可能改變，打點請自己核對），點那位跑者可以改名字、代跑或「刪除這局的突破僵局跑者」。Excel：每位跑者記一列，放在那局最前面（先二壘、再一壘），打擊結果填「突破僵局」、逐球空白；壘上(前)、出局(前)照放上去的順序填（無、2…、0），得分、盜壘、結果代碼照一般跑者記；總表不會把這列算成打席。
>
> **投手犯規**：壘上有人時才有（壘上沒人時的違規投球照規則記一個壞球）。點計分條上的壘包打開跑者面板，按最上面的「投手犯規・全部進壘」：所有跑者各進一壘、這一球不算，打席繼續。我隊投手的投手犯規次數（BK）在「投球」頁「進階」看得到（只在網站計算，Excel 總表不算）；被投手犯規推進回來的分算自責分，沒有打點，也不算盜壘。賽後在「修改資料」點那個打席，在「逐球」選第幾球後、按「投手犯規」，會一次移動所有跑者。Excel 的「跑壘事件」欄寫成「2 投手犯規 3-H；2 投手犯規 1-2」（每位跑者一筆）。
>
> **紀錄比賽替你判斷的事**：第三個出局是封殺（或打者在一壘前出局）時，跑者回本壘不算分：跑者去向預設留在原壘，硬要設成得分會擋下並說明（規則 5.08）；第三個出局是觸殺、接殺後的傳殺時，跑者若在出局前踩到本壘可以算分，畫面會提醒你確認。三振、保送的結果視窗開著時按暴投、捕逸、盜壘，跑者去向會跟著更新。雙殺、野選在「跑者去向」點誰在哪個壘出局，刺殺、助殺就照實際出局的壘算；平飛、高飛的雙殺不算打者的滾地雙殺打。內野滾地出局預設被迫的跑者各進一壘；失誤、野選預設只有被迫的跑者進壘（野選＝一壘跑者出局）。跑者去向有「全部進一壘」「全部不動」，送出前最下面一行寫這次會記成什麼（例如「一安・乙上二壘」）；手機上「送出」固定在畫面底部，送出後自動捲回下一位打者。觸身球、捕手妨礙那一球算進用球數（HP、CI）。兩好球時多一顆「擦棒」（擦棒被捕＝三振）。用「換人」把不是投手的人換到 P＝換投，之後的球算他的。我隊打擊時投手列旁有「對方換投」，點左投／右投就完成。打完規定局數（或最後一局下半主隊領先）會出現「比賽結束」：按「結束比賽」，延長或補記就按「繼續記下一局」。比賽頁的逐局比分，沒打的半局空白，主隊領先不用打的最後半局寫 X。

> **板凳與當日登錄名單**：紀錄比賽時，換投、代打／換人的選單會先列出板凳（標「板凳」），被換下場的人標「已下場」且預設不能再選，這場允許的話在換人工具裡勾「允許再上場」。「換人」可以選任一棒，我隊守備時也能用（守備調動；不選人就是只改守位）。每次換人（代打／代跑／守備／換投、第幾局）都會記下，存檔時連同先發與板凳存成這場的**當日登錄名單**。賽後在「比賽」點那一場，「攻守成績」最下方的「當日登錄名單」列出先發、替補上場（替誰、第幾局）與未上場。以前的比賽沒有名單，先發與替補由打席紀錄推定；紀錄員可以在「修改資料」的「登錄名單」分頁補上或修正（先發、板凳、允許再上場、刪除單筆或清除替補紀錄）。

> **代打之後改守位、失誤算給誰**：代打的人下一局留下來守備、或守備位置互換時，在「換人」選那一棒、不選人、點新的守位就好（只改守位），這也會記進替補紀錄（「換守位 某某 改守 SS」）。我隊守備時，「打線」每一棒旁邊寫「守 6 SS」，還沒有守位的代打會標「代打・沒守位」；「我隊失誤」和跑者「失誤進壘」的守位按鈕會寫現在守那裡的人（「6 SS 王鼎鈞」），點下去就算他的失誤。存檔後，失誤、刺殺、助殺、守備局數都算給**那個半局實際守那個位置的人**（半局中途換人的話，換人之前的打席還是算原來那個人）。以前存的比賽如果算錯人：到「修改資料」→「登錄名單」的「每局守備」看每一局誰守哪裡，不對就點那一局、再點那個守位，選要換上去的人（板凳的人＝上場替下原本的人；場上的人＝改守這裡，他原本的位置會提醒你補人），看一眼確認句子後按「確認」；那一局的變動列在守位下方，可以個別刪除；「我隊投球」的打席會寫「失誤 SS（王鼎鈞）」；「守備」分頁若跳出「守備表的失誤和逐打席紀錄＋登錄名單的守位對不起來」，按「依登錄名單重算失誤」再「儲存修改」。
>
> **報名名單**：杯賽要先報名的，紀錄員到「球員」頁展開名單 →「報名名單」→「新增報名名單」，選年度、填杯賽（例如 2026 大專盃）、點選報名的球員後儲存；同年同杯賽只有一份，再存一次會覆蓋。**杯賽改名**：在「修改資料」或「賽程」把比賽的杯賽改名（例如 秋季聯賽 → 2026秋季聯賽），當年最後一場舊名字的比賽改掉時，報名名單會一起改名（杯賽欄下方會寫「報名名單也一起改名」）；上方的杯賽篩選只列有比賽（打過或排定）的杯賽。報名名單的杯賽沒有任何比賽在用時，名單旁會標警告，點進去按「改成『新名字』」一鍵改好，或按「編輯」自己改杯賽。之後先發陣容與紀錄比賽選到那個杯賽的比賽時，候選名單只列報名的人；沒有名單的杯賽（友誼賽等）照常列出全隊。隊員不用登入也看得到名單；上方篩選選了杯賽時，球員名單可切換「全部球員／報名名單」，報名的人標「已報名」。

**單場-投球 欄位**：局、出局(前)、壘上(前)、對方棒次、投手、對方打者、球1…球12、打擊結果、落點、軌跡、強度、被盜壘、阻殺、暴投、捕逸、牽制出局、守備失誤、結果代碼、備註（最後面還有代跑、打點＝對方打者的打點）。

### 代碼
- 逐球：`SS` 揮棒落空・`CS` 未揮棒好球・`S` 好球（未分類）・`F` 界外・`IP` 擊進場內・`B` 壞球・`T` 擦棒被捕（好球；兩好球時紀錄比賽會多一顆「擦棒」按鈕，按了就是三振）・`HP` 觸身球・`CI` 捕手妨礙（HP／CI 是觸身、妨礙的那一球：算進用球數、跟壞球一起算在好壞球比裡，但不算進球數；紀錄比賽時點「觸身」「妨礙」會自動補上，Excel 自己填的話記在最後一格）
- 打擊結果：一安／內安（內野安打，算一安；預設只有被迫的跑者進壘）／二安／場地二安（彈出或卡在全壘打牆，算二安，跑者都進兩個壘）／三安／全壘打／保送／故四／觸身／三振／內滾／內飛／外飛／界外飛／野選／失誤／犧觸／犧飛／雙殺／妨礙；延長賽照規則放上壘的跑者填「突破僵局」（不是打席）
- 落點：出局填處理球的守備員 1 投 2 捕 3 一壘 4 二壘 5 三壘 6 游擊 7 左 8 中 9 右；沒人碰到的穿越安打填縫隙代碼 56 三游／46 二游／34 一二／78 左中／89 右中
- 名單守位：P／C／1B／2B／3B／SS／LF／CF／RF／DH，或彈性的 IF 內野手／OF 外野手／UT 工具人
- 軌跡：G 滾地／F 飛球／L 平飛／P 內野飛球；強度：強／中／弱
- 在網站「紀錄比賽」時，打進場內的球（三振、保送、故四、觸身、妨礙以外）落點和軌跡必填、強度預設「中」（可改，再點一次可取消）；Excel 匯入不會擋，但匯入報告會列出幾個擊球缺落點／軌跡，「修改資料」也會在我隊打擊、我隊投球清單的那些打席標「缺落點」或「缺軌跡」（兩個都缺就標「缺落點／軌跡」）
- 結果代碼：I／II／III 此打席造成第 1／2／3 個出局・L 殘壘・R 得分（投球表 R 非自責、ER 自責）
- 壘上(前)：無／1／2／3／12／13／23／123

### 小規則
- 雙殺打：只在打者列填代碼，跑者列不要重複填（那一列算 2 個出局）。
- 跑者在壘上出局（盜壘失敗、被觸殺）：在該跑者的列填「壘死」並給出局代碼。
- 網站的「修改資料」：打者安打（或保送、觸身）上壘後在同一個球被觸殺出局（例如三壘安打回本壘被觸殺），在「壘上跑者」把打者設成「出局」，網站會記成壘上出局，安打照算；是他自己跑壘失誤，再點旁邊的「跑壘失誤（壘死）」。紀錄比賽時在「跑者去向」打者那一列點「出局」或「壘死」。以前存的比賽出現「上壘卻記出局碼」的提醒時，到「修改資料」打開那個打席，按提醒下面的「設成壘上出局」就好；匯入 Excel 時出現這個提醒，就在那一列的「壘上出局」填 1。
- 壘死死在哪個壘包：紀錄比賽時，打者（上壘後被刺殺）或「壘死」的跑者設成出局後，下面會出現「死在 1B／2B／3B／本壘」，網站先猜他想跑的下一個壘包（一安→2B、三安→本壘），不對就點正確的；投球之間的壘死（壘上跑者面板按「壘死」）會先問死在哪個壘包。逐球跑壘事件寫「壘死（本壘）」，Excel 的「跑壘事件」欄寫成「2 壘死 3-X 於H 跑者」（於 1／2／3／H）。沒選過的舊紀錄寫他原本站的壘包。
- 換投後還沒面對打者就牽制或阻殺出局：出局和牽制次數算上場的新投手（0.1 局、BF 0）。紀錄比賽時網站自動多記一列結果為「未面對打者」的投球列（不算打席、沒有逐球）；舊比賽到「修改資料」→「投球」，在那一局的標題列按「＋ 換投後出局的投手」補上。這一列要排在該局最後一個打席之後。換投後在新投手第一個打席中途發生的牽制、阻殺，網站依逐球跑壘事件自動算給新投手，不用另外加。
- 軌跡（滾地／飛球／平飛／內野飛球）紀錄比賽時每個擊球都要自己點：內滾、外飛等結果不再自動帶入，沒點不能送出。
- 球員名字要和 `球員名單` 完全一致。

## 四、比賽後（10 分鐘）
1. 檢查 `單場-摘要`：自動算出逐局比分、每人打擊／投球成績；核對 R/H/E。守備區塊填每個人的 PO/A/E（至少填失誤；沒填的 PO／A 網站會由投球紀錄推定）。
2. 貼回總表：`單場-打擊` 有資料的列（A 欄到「對方失誤」欄，最後一個黃色欄；灰色自動欄不用）複製 → `打席紀錄` 最後一列下方 **貼上值**；`單場-投球`（A 欄到「打點」欄）→ `投球紀錄`；守備區塊 → `守備紀錄`。`總表` 立刻更新。
3. 上傳網站：資料匯入 → 密碼登入 → 拖入檔案 → 「合併（略過重複的比賽ID）」。全隊即時看到。
   整份總表、只含三張「單場-」工作表的檔案、或舊格式的單場紀錄表都可以上傳，網站會自動辨識格式並算出一樣的數據：空白的「局」「出局(前)」由出局碼補算，「犧牲」等舊用詞自動對應，沒有守備紀錄時由打席守位與失誤落點推定，並列出需要核對的警告。
4. 貼完可以刪掉單場副本，或保留當存檔。

## 五、賽後怎麼看數據
- **總覽**：戰績、得失分、OPS 走勢、逐局得失分、落點熱區，最下面是「逐季戰績」（每季的戰績、勝率、得失分、AVG、OPS、ERA，點一列就只看那一季）；上方篩選列選杯賽／期間／對手／主客。
- **打擊／投球**：基本、進階、過程指標三組欄位；點標題排序、點球員進個人檔案。BIP（擊球進場）算每一個打進場內的球（三振、保送、故四、觸身、妨礙以外，全壘打也算），不管有沒有記落點、軌跡、強度；GB%／FB%／LD% 只用有記軌跡的球算、Hard% 只用有記強度的、Pull%／Oppo% 只用有記落點的，缺資料不會把比率拉低（Excel 總表一樣）。
- **比賽**：逐局比分、Box Score、當日登錄名單（先發／替補上場／未上場）、逐打席打擊／投球逐球紀錄，以及「文字轉播」分頁（兩隊照時間順序的每個打席一句話，誰跑到哪、誰回來得分都寫出來；逐球表格不變）。
- **即時比分**（比賽中，每 5 秒自動更新，不需登入）：看板由上到下是比分和局數（▲上／▼下，▶ 是正在進攻的隊）、壘包和 S／B／O 燈（中職的順序：好球、壞球、出局）、逐局比分（R H E 永遠在右邊）、投手（今天的局數、安打、失分、四死球、三振、用球數；用球數和紀錄比賽畫面一樣）、打者（今天每個打席和本季成績）、本打席每一球（壞／好／空／界／擊）、壘上是誰、下一棒，最後一行「最新」是兩隊最新的一個動作；兩出局才顯示「攻守交換後」的三棒。看板下面（寬螢幕在右邊）是「文字轉播」：照中職文字轉播的寫法，新的在最上面，得分的打席旁邊有比分、出局的寫幾出局，換投／代打／代跑各一行，每半局寫幾分、幾安打、幾失誤、幾殘壘；點打席看每一球，按「得分」只看得分的打席（較舊的匯入資料沒有「壘上(前)」，看不出是哪一棒送回的，就整個得分的半局留著）。本半局看點的規則沒有改，看板上顯示一行、點一下看全文。
- **即時比分的 Box Score**：看板下面按「文字轉播｜Box Score」切換（會記住你上次看哪個；寬螢幕兩個並排；1920 寬的電視或螢幕開「大螢幕」時，Box Score 在看板右邊）。依序是我隊打擊（棒次・守位・姓名、打數 得分 安打 打點 四死 三振，代打／代跑排在他換下的人下面，最下面合計和二安／三安／全壘打／盜壘）、我隊投球（局數 安打 失分 自責 四死 三振 用球數，正在投的寫「投球中」）、對方打擊（沒記姓名就寫第幾棒）、對方投手（用球數從我隊的打席算）；打擊中的打者有底色，手機上表格在卡片裡左右滑。數字和結束比賽後比賽頁的「攻守成績」一樣，正在打的打席只有用球數先算進去。
- **比賽進行中**：一場比賽還在「紀錄比賽」裡記的時候，比賽頁、比賽列表、總覽的近期比賽、相簿、記分表都寫「比賽進行中」（紅點；總覽「近 5 場」的小格子寫「進行中」），不寫勝或敗；比分是目前的比分，還沒打到的局空白，比賽頁有「看即時比分」。剛打開網站、還沒問到雲端的那一下，今天或昨天的比賽在比賽頁先寫「確認中」。這場也先不算進戰績（勝敗和、勝率、總覽的得失分差和得分／失分、連勝、紀錄簿、逐季戰績），打擊投球數據照算。按「結束比賽」或「放棄」後，最慢 30 秒（重新整理就馬上）變回勝／敗。紀錄到一半放著超過 12 小時沒動的進度，不會再算進行中。
- **球員**：個人數據、隊內百分位雷達、落點分佈、逐場紀錄；展開名單可看各杯賽的報名名單。「生涯」分頁不受篩選影響：逐季成績和生涯合計、個人最佳（單場最多安打、最長連續安打、最長連續上壘…）、里程碑（例如「再 2 支安打就生涯 50 安」）。
- **紀錄簿**：所有比賽的單場、單季、生涯和球隊紀錄前幾名（不受篩選影響）。打擊率、防禦率這類率值要達大專規程的規定打席（2.1 × 場數）或規定局數（1 × 場數）才列入；可以勾「只看現役」、下載 CSV。網站上的「季」預設是西元年；想改成學年制（8 月到隔年 7 月），在部署平台設 `VITE_TEAM_SEASON_START=8`。
- **數據字典**：每項指標的定義與公式。

## 紀錄員輔助：投手休息表、練習紀錄、紀錄員小抄

### 投手休息表
- 「投球」頁右上角「投手休息表」（網址 /pitching/rest，不用登入）：依 **MLB Pitch Smart 19–22 歲的建議**（不是聯盟規定），列出每位投手最近 30 天出賽的日期與用球數、要休幾天、最早哪天可以再投，以及單日超過 120 球、休息不夠就出賽、一天投兩場、連續 3 天出賽、打席沒記球數等提醒。「看哪一天」可以選今天、接下來的賽程或自訂日期。
- 預設級距：1–30 球不用休、31–45 球休 1 天、46–60 球休 2 天、61–80 球休 3 天、81–105 球休 4 天、106 球以上休 5 天；一天最多 120 球、不要連續 3 天出賽、一天只投一場。
- 紀錄比賽時，投手用球數下面會寫「需休 N 天」，快到下一級時提醒「再投 X 球就要多休一天」；休息還沒滿就上場的投手會先寫「休息未滿，10/12（一）起才建議出賽」（橘色）；換投名單標出誰還在休息、誰最近 3 天投過；開賽設定和先發陣容選了投手時會提醒他還要不要休息。這些都只是提醒，不會擋住換投。
- 用球數是紀錄的每一球加總；打席還沒結束就換局（例如盜壘出局結束半局）的那幾球沒有算進去。
- 規則寫在 `web/src/config/teamDefaults.ts` 的 `pitchRest`（每隊各自一份，改了重新部署就生效）。

### 練習紀錄
- 「紀錄比賽」頁上方按「練習紀錄」（還沒登入的話，按登入框下面的「開始練習」；網址 /record?practice=1）：畫面和正式紀錄一樣，**不用登入、不會存檔**。練習只存在這台裝置（和正式比賽的進度分開），不會同步到雲端、不會出現在即時比分，也不算進任何數據。
- 練習中計分條旁有「練習」標籤；按「結束練習」→「結束（不存檔）」就回到練習設定頁。舊版網站（/v/…）沒有練習模式。

### 紀錄員小抄
- 「使用指南」→「紀錄員小抄」（網址 /guide/cheatsheet）：紀錄比賽的每個按鈕和代碼（逐球、打擊結果、落點、軌跡、強／中／弱怎麼判斷、跑者面板、結果代碼、常見情況），按「列印」可以印成一張 A4（深色模式也會印成淺色）。內容從網站的按鈕設定自動產生，按鈕改了小抄也會跟著改。

## 六、常見問題
- **讀取錯誤或記錯了**：到「比賽」點那一場 → 右上角「修改資料」，比賽資訊、每個打席、守備都能直接改、增刪列，儲存後統計立即重算（雲端模式需先登入）。改到一半關掉（✕、點旁邊空白、Esc、上一頁）會先問「有 N 處修改還沒儲存，要離開嗎？」；修改中的內容會留在這台裝置，下次按「修改資料」會先問「接著改」或「丟掉」（按「取消」並確認＝放棄，不會留下）。手機上「儲存修改」固定在畫面底部，旁邊寫幾處修改還沒儲存。插入或刪除打席後，如果那一局的壘上跑者接不起來，儲存前會請你在那局按「依打擊結果重建這局的跑者」（投球之間的盜壘、暴投、牽制會保留）。
- **改了某場資料要重傳**：上傳時選「以此檔取代雲端全部資料」。
- **名字打錯**：總表尋找取代後，用取代模式重傳。
- **ERA 局數**：預設 7 局制；`設定` 工作表或網站資料匯入頁可改 9。
- **寄信登入被限制**：用密碼登入（Supabase → Authentication → Users 設定密碼）。
- **提示「請管理員在 Supabase 執行 supabase/migrations/2026-09-26_rosters.sql」**（管理員）：雲端資料庫還沒加上當日登錄名單（`games.day_roster`）與報名名單（`registrations` 表）。到 Supabase 的 SQL Editor 執行一次這個檔案（重複執行安全），詳見 [SUPABASE_SETUP.md](SUPABASE_SETUP.md)。執行前比賽照常紀錄與儲存，只是登錄名單不會存進雲端、報名名單無法使用、候選名單列出全隊。

## 七、把以前的單場紀錄表匯進來
舊格式（當日比賽統計／打　擊／投球守備）的檔案可以直接轉換：
```bash
python3 tools/convert_single_game.py 舊檔.xlsx --id G20251222-01 --tournament 友誼賽
```
會產生 `data/games/G20251222-01.json`；再執行 `python3 tools/build_workbook.py` 重建總表，網站重新建置後也會內建這場。轉換器會把逐打席推算的逐局得分和記分板比對，不一致時列出警告，請回頭核對原表。
